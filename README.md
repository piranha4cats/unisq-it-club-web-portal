# UniSQ IT Sandbox Club Web Portal

The official web application for the UniSQ IT Sandbox Club, designed to deliver a high-impact, lightweight solution that respects members' study and work commitments[cite: 3]. 

## 🎯 Project Scope
This portal serves two distinct functions:
* **Public-Facing Showcase:** Highlights club projects, features a student journey blog, and demonstrates technical communication skills to potential employers[cite: 3].
* **Members-Only Workspace:** An exclusive hub for club coordination and resource sharing, strictly restricted to `@umail.usq.edu.au` institutional accounts to prevent unauthorized access[cite: 3].

## 🛠 Technology Stack
* **Frontend:** HTML5, CSS3, and Vanilla JavaScript (with lightweight frameworks like Alpine.js if needed)[cite: 3].
* **Authentication:** Supabase Auth or Firebase Authentication[cite: 3].
* **Content:** Embedded objects (Google Drive/Docs, Figma frames, interactive code pens)[cite: 3].
* **Deployment & Version Control:** GitHub and GitHub Pages[cite: 3].

## 🤝 Contributing & Workflow
Our team utilizes an asynchronous-first development model[cite: 3]. We expect a time commitment of 2 to 4 hours per week per member[cite: 1, 3].

**The Golden Rule:** Never save (commit) or push code directly to the `main` branch[cite: 2]. The `main` branch is protected, and all updates must go through a feature branch and a Pull Request (PR)[cite: 2].

### Getting Started
1. **Request Access:** Provide your GitHub-linked email address to the Project Lead to receive repository access[cite: 1].
2. **Clone:** Accept the repository invitation and clone the repository to your local machine[cite: 1, 2].
3. **Claim a Task:** Navigate to the **Web Portal Sprint Board** in the GitHub Projects tab and assign yourself a task from the "To Do" column[cite: 1, 2].
4. **Branch & Code:** Create a feature branch (e.g., `git switch -c feature/navbar-html`), write your code, and commit your work[cite: 1, 2].
5. **Push & PR:** Push your branch to GitHub and open a Pull Request for the team to review[cite: 2].
